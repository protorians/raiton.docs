# Raiton Docs — Night Observatory

**Brief status:** Self-authored under explicit creative delegation.
The user asked for a full art-direction rework of the site using
`murowallpaper.com` as the visual reference, with `scroll-craft` and
`ui-ux-pro-max`. No interview was requested, so the decisions below are authored
within that delegation.

## The eight topics

1. **Vibe.** Nocturnal, precise, quiet, engineered, luminous. References:
   `murowallpaper.com` (the night sky, glass instrument bar, floating app
   window), an observatory control room, a well-set technical manual.
2. **The scroll journey.** Arrival in the night (hero) → proof that the promise
   is real (live request trace) → the pieces (feature bento) → the code (glass
   code windows) → the path from file to deploy (lifecycle) → where to go next
   (documentation constellation) → the release and the one action (start).
3. **Energy curve.** Calm arrival, a small electric pulse at the trace, calm
   reading through the features, a rise at the code, a steady close. Never loud
   for a whole screen; the trace is the one bright instrument.
4. **Feeling, stage by stage.** Curiosity (a sky that is already moving) →
   understanding (the request lights stage by stage) → confidence (the stack is
   visible and small) → appetite (real code, real commands) → resolve (one clear
   next step). The one remembered moment: **the request that lights the whole
   stack in order, and shows the contract as the thing that connects every
   output.**
5. **One thing no other docs site does.** The hero contains a live request
   trace: a signal travels from `POST /api/users` through controller, contract,
   artefacts and response, lighting each stage and reading out the exact
   decorator and artefact produced. It is a documentation diagram that behaves
   like an instrument, not a decorative animation.
6. **Distance from premium-minimal.** Premium-minimal with one authored glass
   layer. Not brutalist, not maximalist; the density stays documentation-grade.
7. **One world or distinct scenes?** One continuous night. The star field is
   fixed behind every page; chapters are lit differently, never cut to a new
   background.
8. **Assets.** Existing logo mark, existing Geist Sans/Mono, existing Markdown
   content. No stock photography. Depth comes from layered CSS, real code, and
   generated light.

## Feeling curve

| Act | Feeling | What causes it |
|---|---|---|
| Arrival | Curiosity | A slow star field, a glass bar, a window of real code floating with its own light. |
| The trace | Understanding | A signal walks the stack; each stage names the decorator and the artefact it produces. |
| The pieces | Confidence | Six glass cards, each one a capability with a doc link; nothing shouts. |
| The code | Appetite | Two real files in glass windows; the command to run them sits between. |
| The path | Orientation | Three steps on a lit rail, from `raiton new` to deploy. |
| The close | Resolve | A release card and a moonlit call to action; the last screen holds. |

**Peak:** the trace. It gets the brightest light, the only continuous motion in
the hero, and the largest single component on the page.

**Tell-someone sentence:** "It's the docs site where you can watch one request
light up the whole framework."

## Grammar and score

Grammar: **Night observatory / chaptered workspace**. A documentation site, not
a film; navigation is persistent, each chapter is a held panel, and the close
is a door rather than a fade.

| Act | Device | Why |
|---|---|---|
| Arrival | Layered hero + pointer parallax | Depth without a video; the code window is the subject. |
| Trace | Bespoke live signal | The signature move; useful, not decorative. |
| Pieces | Spotlight bento | Pointer light reveals the card edge; six capabilities at a glance. |
| Code | Tabbed glass windows | Two real files, no fake screenshots. |
| Path | Lit rail | Sequence is the content here. |
| Close | Held glass panel + moon glow | Resolves instead of trailing off. |

Devices used: parallax, bespoke interaction, spotlight, tabs, rail, reveal.
No device repeats back to back. Reduced motion keeps every state readable and
removes travel, not content.

## Guardrails

- Real markup and real code only; no text baked into images.
- No section counters, no scroll cues, no em dashes in visible copy.
- One peak, one accent family, one continuous night.
- Contrast is measured in both themes; the light theme is a daylight version of
  the same observatory, not a different brand.
