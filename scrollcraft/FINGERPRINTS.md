# Fingerprints

Every site built with **scroll-craft** gets one row here, appended after it
ships. The registry exists so the next build can prove it is a different page
rather than a re-skin of one you already made.

**The gate:** a new build must differ from **every** existing row on at least
four of six dimensions: grammar, nav treatment, hero device, act-sequence shape,
close pattern, signature move. If it fails, change the plan, not the log.
